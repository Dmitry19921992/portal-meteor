## A. Шутер на телефоне (новая раскладка; старая — ☰ → «Телефон» → «Раскладка v7.0»)
1. Слева плавающий джойстик + маленькие «Огонь» (держать — стрелять, кольцо при удержании) и «Ранец» (кольцо — топливо; полёт по взгляду). Справа обзор: по умолчанию свайп; «Обзор: свайп / джойстик» (джойстик — отклонение = скорость поворота).
2. «АВТО» справа (красная, когда вкл.); при ВКЛ «Огонь» гаснет (серая, неактивна).
3. «АВТО»: захват ближайшего видимого врага (конус ~57°, дальность оружия, LOS с кэшем 0.2 с), прицел доводится на цель, стрельба сама; левый джойстик — стрейф/кружение; свайп справа (>38 px) — соседняя цель в сторону свайпа (мягкий магнит); нет целей — обычный обзор. Без «АВТО» — прежняя мягкая помощь в прицеливании (AIMA). Разброс при захвате ×1.35 + 0.004.
4. Красная рамка (только телефон): уголки 1.8 px, разрыв посередине сторон, «закрывается» с 2.2× размера за 0.15 с, пульс уголков, пиксельные засечки; при смене цели переезжает, при потере — разлетается и гаснет (0.32 с). Без «АВТО» рамка бледнее на цели помощи прицеливания.
5. Вверху слева — кнопка «слои»: скрыть/показать миникарту, сообщения, счёт, куратора. Вверху справа (под ☰) — молния: ряд навыков (ракета, рефлекс, удар, оружие; в технике залп/дым/ремкомплект; в дроне таран/ракеты/ремонт/скан). Ранец — своя кнопка слева.
6. Полоска ранца/HP внизу, задача вверху; при смене бойца — короткая плашка «⇆ класс · отряд» (1.7 с), без вспышки и без карточки.
7. Меню телефона: главное и пауза — плитки 4×N без прокрутки; Настройки → разделы (Язык-флаги, Звук, Графика, Управление, Игра, Телефон, Жесты) отдельными экранами; ползунки → «− значение +»; «Назад / ✕ / Применить». ☰ в бою — вкладки «Действия / Вселение / Телефон / Жесты» без прокрутки.
8. Свой набор inline-SVG иконок; короткие подписи, полное название — долгим нажатием (0.5 с); кольца заполнения (ранец, огонь, граната); стрелка ↑ над «Гранатой», когда есть цель; подсказки жестов (тап/держать/свайп/2× тап/щипок) с анимированной рукой, исчезают после первого выполнения (localStorage pm_v71g, сброс в ☰ → «Жесты»).
9. 2× тап справа — рефлекс. Вариант A (по умолч.): тап по рамке — ракета в цель; свайп «Гранаты» вверх — граната в цель (подбор угла/силы тем же интегратором G62, 23 пробных траектории). Вариант B: щипок → «прицел / граната / ракета» (настройка).

## B. Стратегия на телефоне
Тап по своему — выбрать; тап по земле с выделением — идти (2× тап — марш); по врагу — атака; 2× тап по юниту — все такие на экране; держать ~0.38 с (жёлтое кольцо) и отпустить — круговое меню (на земле: Атака, Стоять, Патруль, Строить здесь, Сбор; на юните: Вселиться, способности, Стоять); держать и тянуть — рамка; «Рамка» кнопкой; опция «рамка двумя пальцами» (выкл., тогда зум кнопками ±); один палец — панорама, щипок — зум, поворот двумя пальцами. Справа 8 кнопок: Армия / Пехота / Техника / Дроны / Инженеры / Рамка / Автономно / Следить. Слева карточки отрядов 1-2-3 (тап — выбор, 2× тап — камера). Миникарта сворачивается, тап — камера. Вибро-отклик (navigator.vibrate) на выбор и приказы.
Отклонение: двойной тап по юниту больше не «вселяет» (теперь «все такие»); вселение — «Вселиться» в карточке или в круговом меню. «Патруль» — моя реализация (туда-обратно между лидером и точкой). «Строить здесь» выбирает ближайшего инженера, открывает панель стройки и везёт камеру к точке (место ставится тапом).

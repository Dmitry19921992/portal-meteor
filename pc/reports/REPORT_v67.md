# Portal Meteor v6.7 — отчёт (ветка v67, D:\AI\pm_v6\wt67, коммит 545e753)

## Что сделано (только телефон/сенсор; на ПК код не подменяется — все хуки ставятся под `if (TOUCH.on)`)
- Новый файл `v67_mobile.js` (+ `v67.js` — версия и «Новое в v6.7» RU/EN/VI). Точечно: touch.js (джойстик едет за пальцем, мёртвая зона, плавное угасание, чувствительность), тексты только в TOUCH-ветках (game.js, gun.js, curator.js, v66_voice.js, grenade62.js).
- Шутер: плавающий джойстик + «призрак» слева; обзор — правая половина; справа большая «Огонь» (92 px), вокруг ранец (держать), граната (держать — дуга, вести пальцем, отпустить), прицел, перезарядка, ракета; по ситуации — «Оружие», «Рефлекс», «Удар», «Войти/Выйти»; в технике/дроне — свои кнопки (залп, дым, форсаж, вверх/вниз, таран). Вверху справа «⇆», «◩ Стратегия», «☰». Всё редкое — в меню ☰ (рывок, прыжок, подкат, вид 3-го лица, переброска, в гущу боя, цель) + настройки телефона.
- «Простой огонь» (вкл. по умолчанию, ☰ или Настройки): цель у прицела (из помощи в прицеливании AIMA, с проверкой видимости) → стрельба сама через 0.09 с, отпускание через 0.14 с.
- HUD: только счёт, компактные HP/ранец, патроны по центру внизу; миникарта меньше, слева вверху, тап — свернуть; подсказки с клавишами на телефоне заменены текстами про кнопки или не показываются.
- Стратегия: справа «Вся армия / Отряд (по очереди) / Инженер / Рамка / Автономно»; правая панель только с инженером или заводом (сама закрывается); ИИ-стратег, автостройка, куратор, вкладки панели — в ☰; портрет 84×105 слева, сворачивается; миникарты R=36; куратор одной строкой (тап — развернуть), его метка на карте не мешает тапу.
- Safe area (вырез, полоска «домой») — CSS env() + JS для того, что рисуется на канве (миникарты, стрелка к цели). Портретная ориентация — мягкая подсказка, видна и в меню, кнопка «Играть так». ☰ → «Раскладка v6.6» возвращает старую.

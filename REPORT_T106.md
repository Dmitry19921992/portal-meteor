Идея 2 (принята Дмитрием 07.11): играть в новую тестовую сборку с телефона, без ПК.
Решение: **превью-ветка Cloudflare Pages** того же проекта `portal-meteor` → постоянный адрес
**https://test.portal-meteor.pages.dev/** (production проекта — ветка `main` = portal-meteor.pages.dev, её НЕ трогаем; itch не трогаем).
Превью-деплои Pages бесплатны; Cloudflare сам ставит превью-адресам `X-Robots-Tag: noindex`, мы дублируем в `_headers` и `robots.txt`.

## Вопросы / риски
- Превью-адрес публичный (кто знает ссылку — откроет). Для бесплатной игры это нормально; если нужно скрыть — Cloudflare Access (бесплатно до 50 человек), но это настройка аккаунта — только с «да» Дмитрия.
- 25 МБ на телефоне по мобильной сети — долгая первая загрузка (дальше кэш). Сжатие brotli Pages делает сам.
- Синхронный XHR даёт в консоли предупреждение Chrome (deprecation) — только при выносе словарей, не ошибка.
